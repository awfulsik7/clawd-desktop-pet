# Claw'd на рабочем столе

Маленький пиксельный питомец для Windows. Ходит по панели задач, садится на окна и кнопки, слушает музыку вместе с тобой и иногда что-нибудь говорит.

**[Скачать Clawd.exe](https://github.com/awfulsik7/clawd-desktop-pet/releases/latest/download/Clawd.exe)** · [Сайт](https://awfulsik7.github.io/clawd-desktop-pet/)

> Неофициальный фанатский проект. Не связан с Anthropic и не одобрен ею. Claw'd и Claude — товарные знаки Anthropic.

## Запуск

Скачай `Clawd.exe` и запусти. Нужна Windows 10 (1809 и новее) или Windows 11, ничего устанавливать не надо.

У файла нет цифровой подписи, поэтому Windows может показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

- Перетаскивай питомца мышкой.
- Правый клик — меню: анимации, размер, настройки, «Убрать Claw'd».
- Повторный запуск `Clawd.exe` убирает питомца.

## Что он умеет

- **Живёт на экране.** Гуляет по панели задач, сидит, спит, потягивается, машет лапкой.
- **Садится куда положишь.** На кнопку, обложку альбома, строку списка — и едет вместе с ней при прокрутке.
- **Цепляется.** Висит на верхнем крае окна, держится за бок, ползёт по краю экрана.
- **Повторяет за тобой.** Музыка — наушники, видео — попкорн, игра на весь экран — геймпад, код — ноутбук, мессенджер — телефон. Отошёл — спит.
- **Разговаривает.** Короткие реплики в пиксельном облачке, на русском или английском.

Чтобы подстраиваться, он читает заголовки окон и название того, что сейчас играет. Эти данные никуда не отправляются: программа не выходит в интернет.

## Команды

Запущенному питомцу можно передать команду вторым запуском:

```bash
Clawd.exe --say "готово!"
```

```bash
Clawd.exe --state code
```

Состояния: `code`, `think`, `read`, `coffee`, `music`, `watch`, `game`, `phone`, `eat`, `dance`, `search`, `exercise`, `stretch`, `celebrate`, `love`, `sleep`, `sit`, `idle`, `hang`, `cling`.

## Сборка

Вся программа — один файл `Clawd.cs`. Собирается компилятором C#, который уже есть в Windows:

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

Рядом появится `Clawd.exe`.

## Доработка

Хочешь добавить анимацию, реплики или новое поведение — начни с [CLAUDE.md](CLAUDE.md). Там описано, как устроен файл, какие шесть мест нужно пройти для новой анимации и что легко сломать. Этот же файл автоматически читает Claude Code, так что доработку можно поручить ему.

Все анимации нарисованы кодом, из прямоугольников на сетке; картинок в проекте нет. Облачко с репликами использует шрифт Anthropic Serif Text, если он установлен в системе, иначе Georgia.

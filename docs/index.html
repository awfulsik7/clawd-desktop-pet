Claw'd на рабочем столе

Маленький пиксельный питомец для Windows. Ходит по панели задач, садится на окна и кнопки, слушает музыку вместе с тобой и иногда что-нибудь говорит.

Что он умеет

Живёт на экране

Гуляет по панели задач, сидит, спит в ночном колпаке, потягивается и машет лапкой.

Садится куда положишь

Перетащи его на кнопку, обложку альбома или строку списка — он присядет там и поедет вместе с ней.

Цепляется за окна

Висит на верхнем крае окна, держится за бок, ползёт вверх по краю экрана.

Повторяет за тобой

Музыка — надевает наушники и называет трек. Видео — берёт попкорн. Игра — достаёт геймпад.

Занят делом

Кодит на ноутбуке, читает, пьёт кофе, ищет баги с лупой, делает зарядку и празднует.

Разговаривает

Короткие реплики в пиксельном облачке. Можно выключить одной галочкой.

Смотришь видеоС попкорном, комментирует

Для этого он читает заголовки окон и название того, что играет. Всё остаётся на твоём компьютере: в интернет питомец не выходит вообще.

Как запустить

  1. Скачай Clawd.exe и запусти его. Claw'd упадёт сверху на панель задач.
  2. Windows может показать предупреждение «Система Windows защитила ваш компьютер»: у файла нет платной цифровой подписи. Нажми «Подробнее», затем «Выполнить в любом случае».
  3. Таскай его мышкой. Правый клик открывает меню с анимациями, размером и настройками.
  4. Чтобы убрать, запусти файл ещё раз или выбери «Убрать Claw'd» в меню.

Исходный код открыт: github.com/awfulsik7/clawd-desktop-pet. Программу можно собрать самому одним скриптом, без установки чего-либо.
